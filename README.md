# 🚀 CyberCalc - Futuristic Calculator

A cutting-edge calculator application with a cyberpunk aesthetic, featuring multiple calculation modes, AI-powered natural language processing, and advanced mathematical functions.

## ✨ Features

### 🎯 Multiple Modes
- **Basic Calculator**: Standard arithmetic operations (+, -, ×, ÷, %)
- **Scientific Calculator**: Trigonometric functions, logarithms, powers, constants (π, e)
- **Unit Converter**: Temperature, length, and weight conversions
- **AI Query**: Natural language processing for math questions

### 🎨 Futuristic Design
- Neon cyberpunk aesthetic with glassmorphism effects
- Smooth animations and hover effects
- Gradient backgrounds and glowing borders
- Responsive layout that works on all devices
- Custom scrollbars and interactive elements

### 🧠 Smart Features
- **Calculation History**: Tracks all calculations with timestamps
- **Natural Language Processing**: Ask questions like "square root of 144" or "20 percent of 500"
- **One-click Unit Conversions**: Celsius to Fahrenheit, meters to feet, etc.
- **Scientific Functions**: Complete set of mathematical operations
- **Keyboard Support**: Full keyboard navigation and input

### ⚡ User Experience
- Intuitive button layout with visual feedback
- Real-time calculation display
- Easy mode switching
- History management with clear functionality
- Export calculation history
- Smooth animations and transitions

## 🚀 Getting Started

1. **Clone or Download** the project files
2. **Open** `index.html` in your web browser
3. **Start calculating** with any of the four modes!

## 📱 Usage

### Basic Calculator
- Click number buttons to input values
- Use operator buttons (+, -, ×, ÷) for calculations
- Press = or Enter to calculate
- Use C to clear, ⌫ to backspace

### Scientific Calculator
- Access advanced mathematical functions
- Trigonometric functions (sin, cos, tan, etc.)
- Logarithmic functions (log, ln)
- Power functions (x², x³, √, ∛)
- Constants (π, e)
- Statistical functions (factorial, random, etc.)

### Unit Converter
- **Temperature**: Celsius, Fahrenheit, Kelvin
- **Length**: Meter, Kilometer, Centimeter, Millimeter, Inch, Foot, Yard, Mile
- **Weight**: Kilogram, Gram, Pound, Ounce, Ton
- Enter a value, select units, and click Convert

### AI Query
Ask natural language questions like:
- "square root of 144"
- "20 percent of 500"
- "what is 15% of 200"
- "convert 25 celsius to fahrenheit"
- "area of circle with radius 5"

## ⌨️ Keyboard Shortcuts

- **Numbers (0-9)**: Input numbers
- **Operators (+, -, *, /)**: Mathematical operations
- **Enter or =**: Calculate result
- **Escape or C**: Clear display
- **Backspace**: Delete last character
- **Period (.)**: Decimal point
